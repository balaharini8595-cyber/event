 Introduction

This project demonstrates different types of JavaScript events using HTML, CSS, and JavaScript.
The webpage provides interactive examples of common events such as click, double click, 
mouse hover, key press, focus, and change events.

 Features

* Click Event (`onclick`)
* Double Click Event (`ondblclick`)
* Mouse Over & Mouse Out Events (`onmouseover`, `onmouseout`)
* Key Press Event (`onkeypress`)
* Focus Event (`onfocus`)
* Change Event (`onchange`)
* Responsive and simple UI design

 Technologies Used

* HTML5
* CSS3
* JavaScript

Event Descriptions

 1. Click Event

When the user clicks the button, a message is displayed.

 2. Double Click Event

When the user double-clicks the button, another message is shown.

 3. Mouse Over & Mouse Out Events

When the mouse enters the orange box:

* Background color changes to red
* Text changes to "Mouse Over"

When the mouse leaves the box:

* Background returns to orange
* Original text is restored

 4. Key Press Event

Displays the key pressed by the user inside the text box.

 5. Focus Event

When the input field gains focus:

* Background color changes to light yellow
* Focus message is displayed

 6. Change Event

When a food item is selected from the dropdown:

* Selected item name is displayed
